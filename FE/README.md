# Nam Dương Salon - Frontend

Giao diện demo được xây dựng bằng Expo, React Native, TypeScript và Expo Router.

## Chạy dự án

```bash
npm install
npm start
```

Sau khi Metro khởi động:

- Quét mã QR bằng Expo Go để chạy trên điện thoại.
- Nhấn `w` để mở bản web.
- Điện thoại và máy tính cần cùng mạng Wi-Fi khi dùng kết nối LAN.

## Đăng nhập demo

Nhấn **Đăng nhập**, nhập tên và mật khẩu bất kỳ. Sau khi đăng nhập, nút trên thanh điều hướng sẽ hiển thị tên người dùng. Đây mới là trạng thái giao diện cục bộ, chưa kết nối backend hoặc cơ sở dữ liệu.

## Thư mục chính

- `src/app`: màn hình và điều hướng Expo Router.
- `src/components`: thành phần giao diện dùng lại.
- `src/data`: dữ liệu mẫu cho trang chủ.
- `assets/images`: hình ảnh của ứng dụng.
